# 🌿 Herbal Tea Shop

A modern, responsive, and dynamic herbal tea shop website built with **Next.js**. This project demonstrates dynamic data rendering, API integration using JSON Server, and a clean component-based architecture.

---

## 🚀 Features

- Responsive design for desktop, tablet, and mobile
- Dynamic content powered by `db.json`
- Data fetching using the Fetch API
- Customer testimonials loaded dynamically
- Reservation form
- Contact form
- Newsletter subscription
- Dynamic routing with Next.js
- Swiper slider integration
- Server-side rendering strategies using Next.js
- Component-based architecture
- Images served from the `public` directory

---

## 🛠️ Tech Stack

- Next.js
- React.js
- JavaScript (ES6+)
- CSS3
- Fetch API
- JSON Server
- Swiper.js

## 📡 Data Management

All project data is stored inside the `db.json` file and served using **JSON Server**.

The website dynamically fetches data including:

- Testimonials
- Reservation data
- Contact form submissions
- Newsletter subscriptions

User submissions are stored in `db.json`, simulating a simple backend environment.

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/yeganehrezzd/Tea-Bliss.git
```

Go to the project directory:

```bash
cd herbal-tea-shop
```

Install dependencies:

```bash
npm install
```

Run JSON Server:

```bash
npm run server
```

Start the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
